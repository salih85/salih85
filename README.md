**Features:** 👥 Multi-user Editing • ⚡ Real-Time Sync • 🔄 CRDT Conflict Resolution • 🧩 Drag & Drop Editor • 📝 Text Blocks • 🖼️ Images • 🎥 Videos • 🔐 Permissions • 👑 Owner/Participant Roles • 📹 WebRTC Video Calls • 🔑 OAuth

**Stack:** `React` `Node.js` `WebSockets` `Yjs` `WebRTC` `OAuth`
